# 편집 규칙집 (Editing Rulebook)

> **상태: 임시본(provisional)** — 레퍼런스 3개 영상(유튜브 쇼츠)을 이 환경에서 내려받지 못해(네트워크가 youtube.com 을 403 차단),
> 아래 수치는 한국어 숏폼 정보형 영상의 일반 관행으로 채운 **초기값**입니다. 레퍼런스 실측값이 아닙니다.
> 네트워크를 열고 `python3 ve.py analyze <링크3개> --apply` 를 한 번 실행하면 이 문서의 수치와 `rules/rules.json` 이 실측값으로 교체됩니다.
> (분석기는 합성 영상으로 검증 완료: 컷 감지·자막 OCR·크기·위치·LUFS·효과음 후보 추출)

이 문서가 사람이 읽는 규칙집이고, 편집기는 같은 내용을 `rules/rules.json` 에서 읽어 그대로 적용합니다. 피드백은 맨 아래 **사용자 피드백 누적**에 자동으로 쌓이고 JSON 에 반영됩니다.

## 0. 캔버스
| 항목 | 값 |
|---|---|
| 해상도/비율 | 1080×1920, 9:16 세로 |
| 프레임레이트 | 30fps |
| 가로 촬영본 | 블러 배경 위에 화면 전체가 보이게 얹음(`fit_blur`), 세로 촬영본은 꽉 채움 |
| 길이 | 60초 이하 권장 (QA가 경고) |
| 화면 하단 20%·상단 8% | UI 가림 영역 → 중요한 글자 금지 |

## 1. 컷 (장면 전환) 리듬
| 규칙 | 값 | 이유 |
|---|---|---|
| 한 컷 최대 길이 | 2.6초 (`cut.max_shot`) | 숏폼은 2~3초마다 화면이 바뀌어야 이탈이 적음 |
| 한 컷 최소 길이 | 0.9초 | 너무 짧으면 정신없음 |
| 말 앞/뒤 여유 | 앞 0.05초, 뒤 0.10초 | 호흡 잘림 방지, 군더더기 무음은 제거(점프컷) |
| 무음 기준 | -35dB, 0.30초 이상 | 이보다 긴 침묵은 삭제 |
| 대본 한 줄 | 최소 한 컷. 2.6초를 넘으면 균등 분할 | |
| 컷이 바뀔 때 | **확대 배율을 반드시 바꿈** (1.00 ↔ 1.14 교대) | 같은 화면이라도 점프컷 느낌을 줘서 단조로움 방지 |
| 컷 길이 | 5컷 연속 같은 길이 금지(QA) | 기계적 리듬 방지 |

## 2. 화면 확대(줌)
- 평상시 교대 배율 1.00 / 1.14 (정적 펀치인, 컷 경계에서만 변함).
- 인트로 첫 컷은 1.16 로 시작해 시작부터 에너지를 줌.
- 자료화면은 1.08 배율.
- 정지/무변화 3초 이상이 감지되면 그 지점에서 컷을 쪼개고 배율을 바꿈(자동 수정).

## 3. 자막 (기본)
| 항목 | 값 |
|---|---|
| 글꼴 | 나눔스퀘어라운드 Bold (`NanumSquareRound`) |
| 크기 | 78px (1080폭 기준) |
| 글자색 | 흰색 `#FFFFFF` |
| 외곽선 | 검정 7px + 그림자 2px |
| 위치 | 화면 하단에서 560px 위(세로 약 70%), 가운데 정렬 |
| 줄 | 한 줄 12자 이내, 최대 2줄 |
| 나타나는 방식 | 대본 한 줄 = 한 컷 동안 표시, 줄이 길면 글자 수 비율로 페이지 분할 |
| 핵심 단어 | 같은 줄 안에서 노란색 `#FFE600` 로 색 변경 (`*단어*` 표기) |
| 맞춤법 | 자동 교정 사전(`typo_fixes`) 적용 후 QA가 재검사 |

## 4. 강조 자막
| 항목 | 값 |
|---|---|
| 뜨는 순간 | 해당 단어가 말해지는 시점(줄 안의 글자 위치 비율) |
| 모양 | 노란색 128px, 검정 외곽 11px, 화면 가운데(y=760) |
| 움직임 | 60% → 118% → 100% 팝(0.12초씩) |
| 유지 | 0.9초(문장이 먼저 끝나면 거기까지) |
| 효과음 | 같은 순간 `pop` |
| 개수 | 대본에서 `*…*` 로 표시된 것만. 한 영상 5~8개 권장 |

## 5. 효과음
| 상황 | 소리 | 타이밍 | 볼륨 |
|---|---|---|---|
| 대본 줄이 바뀔 때(컷 전환) | whoosh | 전환 0.05초 전 | -9dB |
| 강조 자막 | pop | 자막과 동시(0.05초 전) | -9dB |
| 인트로 시작 | hit(저음) | 0초 | -9dB |
| 아웃트로 CTA | ding | CTA 표시 시작 | -9dB |
- 사용자 효과음은 `assets/sfx/whoosh.wav, pop.wav, hit.wav, ding.wav` 로 넣으면 합성음 대신 사용.

## 6. 배경음
- 가벼운 루프 BGM, 목소리 대비 -24dB, 시작 0.5초 페이드인.
- **목소리가 나올 때 자동으로 더 낮아짐**(사이드체인 덕킹), 끝에서 페이드아웃.
- 최종 음량 -14 LUFS(true peak -1.5dB).
- 내 BGM 은 `assets/bgm/` 에 넣으면 사용(저작권 확인 필요).

## 7. 자료화면
- 대본에 `[자료: 파일명]` 이 있는 줄에서 사용. 목소리는 유지, 화면만 자료로 교체.
- 가로 자료는 블러 배경 + 전체 보임, 1.08배 서서히 확대 느낌의 배율, 교체 순간 whoosh.
- 자료화면 위에도 자막은 동일 규칙.

## 8. 인트로
- 첫 줄은 **훅**: 첫 1.8초 동안 화면 위쪽(y≈520)에 노란색 96px 팝 자막(줄바꿈 9자)으로 크게, 일반 자막은 이 시간 동안 숨김.
- 0초에 hit 효과음, 첫 컷 1.16배. 로고·타이틀 카드 없이 바로 시작(이탈 방지).

## 9. 아웃트로
- 마지막 2.0초: 하단(y=1500)에 CTA 문구 "팔로우하고 다음 영상도 받아가세요" 56px 흰색, 페이드 인/아웃, ding.
- 오디오는 마지막 1.2초 페이드아웃. 별도 엔드카드 없음.

## 10. 개인정보 보호
- 최종 영상을 0.5초마다 OCR → 전화번호, 주민번호, 카드/계좌번호, 이메일, 비밀번호/토큰/API 키 문구, 도로명 주소가 보이면 해당 구간·위치를 자동 블러(앞뒤 0.6초 여유).
- 한계: 이름·얼굴·한글 주소의 일부는 OCR 인식률이 낮아 놓칠 수 있음 → 결과 보고서의 "화면 확인 필요" 안내를 한 번은 눈으로 확인.

## 11. 자체 검수 체크리스트(자동 실행)
1. 자막 오타: 대본 대조 + 맞춤법 사전 + 단어 중복/자모 단독/띄어쓰기
2. 반복: 다른 위치에서 같은 장면 재등장, 컷 길이 단조
3. 정지: freezedetect 1.2초 + 화면 변화 없음 3초 → 컷 분할 자동 수정(최대 2회)
4. 개인정보: 위 10번
5. 규격: 1080×1920, 길이 60초 이하
