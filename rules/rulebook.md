# 편집 규칙집 (Editing Rulebook)

> **상태: 1편 실측 반영(derived-from-ep1)** — 사용자가 올린 **완성본 1편**(28.5초, 1080×1920, 30fps)을 컷·자막·소리 단위로 직접 분해한 값입니다.
> 유튜브 레퍼런스 3개는 아직 분석 전입니다(youtube 도메인 허용 후 `python3 ve.py analyze <링크…>` 로 보강).
> 한글 OCR 자동 분석은 부정확해서(자막이 깨져 인식됨) 수치는 프레임을 눈으로 보고 측정했습니다. 근거 프레임: `reference/ep1/sheet*.png`.
> 편집기는 같은 내용을 `rules/rules.json` 에서 읽습니다. 피드백은 맨 아래에 자동 누적됩니다.

## 0-1. 출력 파일 규격 (1편 완성본과 동일, 2026-10-26 사용자 요청)
QuickTime `.mov` / HEVC(H.265) Main 프로파일 레벨 4.0, 태그 `hvc1` / 1080×1920, 30fps 고정 / yuv420p, BT.709, 제한 범위(tv) / 영상 약 7Mbps, B프레임 없음, 키프레임 30프레임 / 오디오 AAC-LC 스테레오 44.1kHz 약 96kbps.
모든 편집 결과는 자동으로 이 규격의 `.mov`로 저장(`videoedit/export.py`). 편집 중간 확인용 mp4가 함께 남지만 전달 파일은 `.mov`.

## 0. 캔버스
1080×1920(9:16), 30fps, 28초 안팎. 하단 20%·상단 8%에는 중요한 글자 금지.

## 2. 컷
- **하드컷만** 사용(디졸브·와이프 없음). 한 컷 대부분 **2.0초 전후**(1.5~2.1초), 설명이 긴 구간만 4~6초 한 컷(바지 펼침 5.7초는 키워드 5개로 리듬을 만듦).
- 컷마다 **옷/동작/구도가 바뀜**. 같은 구도를 길게 두지 않음.
- 화면 확대(줌), 속도 변화, 효과 전환 **없음**. (정지 사진을 쓸 때만 정지로 보이지 않게 4% 정도 천천히 이동)
- 첫 0.3초는 훅 자막이 뜬 상태에서 시작, 로고·타이틀 카드 없음.

## 3. 자막 5종 (실측 스타일)
| 종류 | 용도 | 모양 |
|---|---|---|
| ① 훅 | 첫 컷 | 흰색, 굵은 고딕, 약 104px, 화면 위 1/3(y≈33%) 가운데, 4줄(한 줄 7자 안팎), 외곽선·그림자 없음 |
| ② 일반 자막 | 말하는 내용 | 흰색 고딕, 약 54px(1080 기준), 하단(y≈79%) 가운데, 한 줄, 가는 그림자만. 문구가 바뀌면 교체 |
| ③ 라벨+체크리스트 | 상황 설명 | 검정 둥근 라벨(흰 굵은 글씨 약 58px, y≈70%), 그 아래 작은 흰 글씨 항목이 **말하는 순서대로 하나씩 추가**, 앞에 ✓ |
| ④ 키워드 쌓기 | 항목 나열(3개 이상) | 흰 글씨 약 58px, 화면 중앙 세로 한 줄로 y≈20%·31%·43%·54%·66%에 **1초 간격으로 하나씩** 나타나 끝까지 유지 |
| ⑤ 제목 | 마지막 제목·강한 강조 | 둥근 굵은 글씨, 흰색 채움 + 얇은 검정 안쪽 선 + 두꺼운 흰 바깥 선(스티커 느낌), 약 100px, y≈47%, 2줄 |
- 노란색 강조, 팝 애니메이션, 크기 변화 애니메이션 **없음**(전부 흰색, 등장은 바로 나타남).
- A/B 분할 컷에서는 영상 영역을 y 21%~79%로 두고 위아래는 검은색.

## 4. 소리
- **배경음 없음**(무음 구간 -65dB). **효과음은 확인되지 않음**(컷 순간의 별도 소리 없음).
- 목소리만 있고 음량은 평균 약 -34dB(피크 -15dB, 영상 전체 LUFS -30).
- 2편은 목소리를 사용자가 나중에 입히므로 편집기는 **무음 트랙 + 자막만** 출력(배경음·효과음 기본 꺼짐). 필요하면 규칙(`bgm.enabled`, `sfx.*`)을 켜면 됨.

## 5. 인트로 / 아웃트로
- 인트로: 0초부터 훅 자막이 뜬 정면 전신, 훅이 곧바로 질문 형태.
- 아웃트로: 별도 엔드카드·CTA 효과 없음. 마지막 4초 정면 컷에 **제목(⑤)**을 띄우고 마지막 1.5초에 하단 일반 자막으로 참여 유도 한 줄.

## 6. 자료화면
- 이 영상에는 외부 자료화면이 없고 **전부 직접 촬영한 컷**. 가로 자료는 블러 배경 위 전체 표시(기본값 유지).

## 7. 개인정보
- 최종 영상 OCR로 전화번호·주민번호·카드/계좌·이메일·키/비밀번호·도로명 주소 자동 블러. (한글 이름·얼굴은 놓칠 수 있어 육안 확인)

## 8. 자체 검수 (자동)
자막 오타(대본 대조·맞춤법 사전) / 반복 장면·단조로운 컷 길이 / 3초 이상 변화 없는 화면·정지 / 개인정보 / 규격(1080×1920, 60초 이하).

## 9. 2편 대본 → 스타일 매핑 규칙
대본 `크게:`(첫 블록)=① 훅, `크게:`(그 외)=⑤ 제목, `자막:`=② 일반, `태그:` 1~2개=③ 라벨, 3개 이상=④ 키워드 쌓기.

- [2026-10-11] 피드백: "큰 자막(제목 스타일)은 줄바꿈 하지 말기" → 큰 자막은 항상 한 줄, 길면 글자 크기만 자동 축소 (`caption_style.title.wrap=false`, `max_width_px=960`). 훅(첫 블록 큰 자막)은 기존처럼 여러 줄.
- [2026-10-11] 피드백: "2편 훅 자막/마지막 '다음 편' 태그 삭제, 5초 컷 3배 줌, 마지막 삽입 영상 얼굴 크롭" → 해당 편 대본·클립 매핑에 반영(편별 설정). 얼굴 노출 컷은 얼굴 아래만 남기도록 확대 크롭하는 옵션(zoom/cx/cy) 사용 가능.

- [2026-10-11] 피드백: "마지막에 CTA 삽입" → 영상 마지막 1.5초에 하단 일반 자막 스타일(흰색 작은 글씨, 페이드인)로 CTA 한 줄. 대본에 `CTA:` 로 적음. 이후 편에도 기본으로 마지막에 CTA를 넣을 것.

- [2026-10-26] 피드백: "5편은 1편과 내용만 다르고 자막 스타일·제목 스타일·편집기술이 모두 동일" → **모든 편은 1편 형식 고정.** 1편 원본 실측값(1080×1920 기준): 훅 약 150px 흰색·줄 간격 약 204px·화면 중앙(y≈49%) / 일반 자막 약 75px y≈78% / 분할 영상 띠 y 22~78%, 그 아래 검은 영역 자막 약 88px y≈84% / 하단 작은 문구 약 50px y≈82% / 제목 스티커 약 133px y≈50% / 라벨 약 56px y≈71% / 키워드 약 80px(y 20·31·43·54·66%). 편집은 약 1.5~2.1초 하드컷(불규칙), 확대·속도·효과음·배경음 없음, 분할 컷 위에는 큰 글씨 대신 아래 검은 영역에 자막. 대본의 연출 지시가 이와 충돌하면 1편 형식을 우선하고 보고서에 알림.

- [2026-10-26] 피드백: "비교 컷은 둘 다 동일한 자세, 움직이거나 뒤돌거나 각도 다른 컷은 교체" → 좌우 분할 비교 컷에는 양쪽이 같은 자세·같은 각도·같은 방향이며 둘 다 거의 움직이지 않는 구간만 사용(정지 구간 탐지 + 육안 확인). 정면은 손 내림, 측면은 같은 방향 옆모습.
